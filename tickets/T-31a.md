**Flujo del spec** (selectores por rol, `aria-label` o texto visible; **nunca clases CSS**):
1. Arranque: medir el tiempo desde la creación de la sesión WebDriver hasta que se ve el formulario de conexión rápida. Es el **arranque en frío**: se mide 3 veces relanzando la sesión y se toma la mediana.
2. Conexión rápida a `127.0.0.1:2222`, usuario `tuki-bash` y contraseña `tuki-test`:
   - si aparece el diálogo de huella del host, se acepta (puede no aparecer si ya se conoce);
   - se espera la terminal y el sidebar de SFTP.
3. Escribir `cd /tmp` + Enter en la terminal (xterm recibe el foco en su textarea accesible) → el sidebar muestra la ruta `/tmp` en ≤ 5 s, con "Seguir terminal" marcado.
4. Crear un archivo remoto con un nombre único (`echo e2e > /tmp/e2e-<ts>.txt` en la terminal) → aparece en el sidebar (refrescar si hace falta).
5. Menú contextual → "Descargar" → el archivo aparece en la carpeta Descargas del usuario con el contenido `e2e`. El test **lo borra al final**.
6. **RAM en reposo:** 5 s después de conectar, sumar el working set privado del proceso de la app y de sus descendientes WebView2 (PowerShell `Get-CimInstance Win32_Process`, recorriendo el árbol por `ParentProcessId`; en Linux, `/proc` por PPID).
7. Imprimir una tabla Markdown con el arranque en frío y la RAM, sus metas y PASS/FAIL. Si existe `GITHUB_STEP_SUMMARY`, añadirla ahí. **Los KPIs se reportan pero no hacen fallar el spec** (la línea base se fija con el humano); los pasos funcionales 2–5 sí lo hacen.

**Subida:** solo existe arrastrando desde el SO, y WebDriver no puede automatizarlo. Ya está cubierta por los tests de integración; queda en el checklist manual T-36. Se documenta en un comentario del spec.

**Reglas de `e2e:`:**
1. Levanta el contenedor (como `test-int`).
2. `npm --prefix ui run tauri build -- --no-bundle`.
3. `npm --prefix e2e ci`.
4. `npm --prefix e2e test`.

**Job `e2e-linux`** (`if: workflow_dispatch || tags`, `ubuntu-22.04`):
- dependencias de `ci.yml` + `webkit2gtk-driver` + `xvfb`;
- `cargo install tauri-driver --locked`;
- `xvfb-run just e2e`.
