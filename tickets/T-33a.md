## T-33a: Bundle configuration and `just bundle`
**Fase:** F7  **Depende de:** T-34b
**Contexto:** Dejar listo el empaquetado local de Tauri por SO. El workflow con tag va en T-33c.

**Archivos a crear/modificar:**
- `crates/desktop/tauri.conf.json` (modificar: sección `bundle`)
- `justfile` (modificar: receta `bundle`)
- `crates/desktop/tests/bundle_config.rs` (crear: test que lee el JSON con `serde_json`, ya en las dependencias)

**Reglas (`bundle`):**
- Básicos:
  - `"active": true`;
  - `"targets": ["nsis", "msi", "appimage", "deb", "dmg", "app"]` (Tauri ignora los que no corresponden al SO);
  - `"category": "DeveloperTool"`;
  - `"license": "MPL-2.0"`, `"licenseFile": "../../LICENSE"`;
  - `"shortDescription"` en ≤ 80 caracteres y `"longDescription"`, ambos en inglés.
- `"publisher": "tukitermlulu"` y `"homepage": "https://github.com/Leuname0410/tukitermlulu"`.
- `"copyright"` con el año actual.
- Windows: NSIS `installMode: "currentUser"` (sin admin).
  - WebView2 con `webviewInstallMode` `downloadBootstrapper`: el instalador más pequeño posible, por el KPI de < 15 MB.
- Linux: `deb.depends` vacío salvo lo que Tauri añade (no añadir paquetes a mano).
- macOS: `minimumSystemVersion: "10.15"`.
- Se conservan los `icon` actuales. No se añade `updater` ni firma (T-33b, T-33c).
- `justfile`:
  - `bundle: npm --prefix ui run tauri build` (con `--target universal-apple-darwin` solo cuando el SO es macOS, usando `os()` de just);
  - `bundle-size:` imprime el tamaño en MB de cada instalador de `target/**/release/bundle/` (PowerShell en Windows y `du`/`find` en Unix, aprovechando `windows-shell` que ya está definido).

**Criterios de aceptación:**
- [ ] El test `bundle_config` verifica `active`, los 6 targets, `license == "MPL-2.0"`, que `licenseFile` existe en disco y que `shortDescription` tiene ≤ 80 caracteres, `installMode == "currentUser"` y `minimumSystemVersion`.
- [ ] `just check` en verde.
- [ ] (El orquestador, en Windows) `just bundle` genera `.msi` y `-setup.exe`, y `just bundle-size` lista sus tamaños.

**Commits:** `test(desktop): bundle config [T-33a]` → `feat(desktop): bundle config and just bundle [T-33a]`

**Fuera de alcance:** CI de release, firma y notarización, auto-update.
