## T-23c: Add the SftpSidebar UI, opened automatically beside the terminal
**Fase:** F5  **Depende de:** T-23b
**Contexto:** Decisión D1: al conectar una pestaña se ven a la vez el **sidebar SFTP a la izquierda** y la terminal a la derecha, sin acción del usuario. El sidebar arranca en `sftpHome` y permite navegar. El seguimiento del directorio de la terminal llega en F6 (T-30); aquí solo se deja la prop `path` controlable desde fuera.

**Archivos a crear/modificar:**
- `ui/src/sftp/sidebarModel.ts` (crear: lógica pura)
- `ui/src/sftp/SftpSidebar.tsx` (crear)
- `ui/src/sftp/sftp.test.tsx` (crear)
- `ui/src/tabs/TabsView.tsx` (modificar: con `connected`, panel en 2 columnas `SftpSidebar | TerminalView`; ancho fijo del sidebar, 280 px, hasta T-25)

**Interfaces / firmas esperadas:**
```ts
// sidebarModel.ts
export type SortKey = "name" | "size";
export function sortEntries(entries: readonly EntryDto[], key: SortKey, ascending: boolean): EntryDto[];  // carpetas siempre primero; nombre con localeCompare numérico
export function parentPath(path: string): string | null;    // "/" → null; "/a/b" → "/a"; "/C:/x" → "/C:/"
export function formatSize(bytes: number): string;          // "0 B", "1.5 KiB", "2.0 MiB"…
// SftpSidebar.tsx
export interface SftpSidebarProps { connectionId: number; path?: string; onPathChange?(path: string): void }
export function SftpSidebar(props: SftpSidebarProps): JSX.Element;
```
**Comportamiento:**
- Al montar: `sftpHome(connectionId)` → `sftpList`. Si llega `path` desde fuera, se lista esa ruta.
- Barra superior: campo de ruta editable (`aria-label="Ruta remota"`, Enter navega), botones con `aria-label` "Subir de nivel" (deshabilitado en `/`) y "Refrescar".
- Lista `role="grid"` (o `table`) con icono de carpeta o archivo (SVG inline o carácter; sin dependencias nuevas), nombre y tamaño; las cabeceras "Nombre" y "Tamaño" ordenan y alternan asc/desc.
- Doble clic o Enter sobre una carpeta → navega; sobre un archivo → nada (descargar llega en T-24/T-26).
- Mientras carga: `aria-busy`. Un error (`permission_denied`, `not_found`) se muestra en la barra y se conserva el listado anterior.
- Toda la lógica de orden y rutas va en `sidebarModel.ts`.

**Criterios de aceptación (Vitest + Testing Library, `vi.mock("../lib/api")`):**
- [ ] `sortEntries`, `parentPath` y `formatSize`: tablas de casos (incluye `/C:/` y números en nombres: `file2` < `file10`).
- [ ] Al montar se llama a `sftpHome` y luego a `sftpList` con su resultado; se ven las entradas, carpetas primero.
- [ ] Doble clic en una carpeta → `sftpList(path/carpeta)`; "Subir de nivel" → el padre; "Refrescar" → vuelve a listar la misma ruta.
- [ ] Editar la ruta + Enter → lista esa ruta; un error se muestra y la lista anterior sigue visible.
- [ ] Ordenar por tamaño invierte al pulsar dos veces.
- [ ] En `TabsView`, una pestaña `connected` muestra a la vez la región "Terminal" y el sidebar (por rol/etiqueta); las otras pestañas no.
- [ ] `just check` en verde.
