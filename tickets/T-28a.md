## T-28a: Forward the terminal working directory from the PTY stream to the UI
**Fase:** F6  **Depende de:** T-27 · **ADR:** 005, 006
**Contexto:** El `ChannelSink` (T-15a) pasa cada fragmento de salida por el `Osc7Tracker` (T-27) **sin modificar los bytes** que van a xterm. Cuando el directorio cambia, lo envía por un tercer `Channel` (`on_cwd`). La UI guarda el último cwd **en el controlador de la pestaña** (no en estado de React por cada byte): solo el cambio de directorio, que es raro, llega al reducer.

**Archivos a crear/modificar:**
- `crates/desktop/src/terminal.rs` (modificar: `ChannelSink` gana `tracker: Osc7Tracker`, `last_cwd: Option<RemotePath>` y `cwd: Channel<CwdChanged>`; `connect` recibe `on_cwd: Channel<CwdChanged>`)
- `ui/src/lib/api.ts` (modificar: `TerminalHandlers.onCwd?(path: string)`; `connect` crea el tercer `Channel` y valida la carga `{ path: string }`)
- `ui/src/lib/api.test.ts` (modificar)
- `ui/src/tabs/tabState.ts` (modificar: `Tab.cwd?: string` + acción `{ type: "cwd"; id; path }`)
- `ui/src/tabs/tabController.ts` + `ui/src/tabs/tabs.test.ts` (modificar: `onCwd` → `dispatch({ type: "cwd" })`)

**Interfaces / firmas esperadas:**
```rust
#[derive(Serialize, Clone)] pub struct CwdChanged { path: String }
impl PtySink for ChannelSink {
    fn data(&mut self, bytes: &[u8]) {
        let _ = self.output.send(InvokeResponseBody::Raw(bytes.to_vec()));   // primero, sin tocar
        if let Some(path) = self.tracker.feed(bytes) { if self.last_cwd.as_ref() != Some(&path) { /* send CwdChanged; last_cwd = path */ } }
    }
}
```
**Reglas:**
- Los bytes de salida se envían **antes** de analizarlos y sin cambios.
- Solo se emite cuando el directorio cambia (`cd .` repetido no emite).
- Si falla el envío del canal, se ignora.

**Criterios de aceptación:**
- [ ] Rust unit con `Channel::new` capturando: un fragmento con texto + OSC 7 → la salida raw es idéntica al fragmento y `on_cwd` recibe `/tmp`.
- [ ] La misma ruta dos veces → un solo `CwdChanged`; otra ruta → otro.
- [ ] OSC 7 partida entre dos `data` → un `CwdChanged` tras el segundo.
- [ ] UI: un mensaje `{ path }` en el canal llama a `onCwd`; uno mal formado se descarta.
- [ ] Reducer: la acción `cwd` actualiza `tab.cwd` solo de esa pestaña; el controlador la despacha.
- [ ] `just check` en verde.
