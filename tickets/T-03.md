## T-03: Add GitHub Actions CI with a Linux/Windows/macOS matrix
**Fase:** F0  **Depende de:** T-02
**Contexto:** El CI ejecuta el mismo gate que en local (`just check`) en los tres SO, con caché. Según el plan (riesgos §8), macOS solo corre en PR a `main`; Linux y Windows en cada push y PR.

**Archivos a crear:**
- `.github/workflows/ci.yml`

**Estructura esperada:**
- `name: CI`; `on`: `push` (todas las ramas) y `pull_request` (a `main`).
- `concurrency: { group: ci-${{ github.ref }}, cancel-in-progress: true }`; `permissions: { contents: read }`.
- Job `check`, `strategy.fail-fast: false`, `matrix.os: [ubuntu-latest, windows-latest, macos-latest]`.
  - Excluir macOS cuando no sea PR: `if: matrix.os != 'macos-latest' || github.event_name == 'pull_request'` a nivel de job no funciona con matrix → aplica la condición en **cada paso** o genera la matriz con una expresión (`fromJSON`); elige la opción más simple y legible.
- Pasos (en orden):
  1. `actions/checkout@v4`
  2. `dtolnay/rust-toolchain@stable` con `components: clippy, rustfmt`
  3. `Swatinem/rust-cache@v2`
  4. Solo Linux: `sudo apt-get update && sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf libxdo-dev libssl-dev build-essential`
  5. `actions/setup-node@v4` con `node-version: lts/*`, `cache: npm`, `cache-dependency-path: ui/package-lock.json`
  6. `taiki-e/install-action@v2` con `tool: just,cargo-audit,cargo-deny`
  7. `npm --prefix ui ci`
  8. `npm --prefix ui run build` (para que exista `ui/dist`)
  9. `just check`
- Sin secretos, sin `pull_request_target`, sin pasos de release/bundle.

**Criterios de aceptación (verificables):**
- [ ] El YAML es válido (`actionlint` si está disponible; si no, parseo YAML con node/python) y usa solo las acciones listadas.
- [ ] Ninguna receta de `justfile` ni otro archivo cambia: el CI invoca `just check` tal cual.
- [ ] Linux/Windows corren en push; macOS solo en `pull_request`.
- [ ] (Humano, tras push) El PR muestra checks en verde en los tres SO.

**Tests requeridos:** ninguno (infraestructura).
**Commit:** `ci: add github actions matrix running just check [T-03]`

**Fuera de alcance:** release/bundling, e2e, cobertura, dependabot, cambios al `justfile` o a dependencias.
