## T-13a: Extend the SshTransport port with host-key handshake and the PTY data plane
**Fase:** F3  **Depende de:** T-12b · **ADR sugerido:** 005 (plano de datos de la terminal en los puertos)
**Contexto:** El puerto de T-08a no permite (1) que el caso de uso verifique la huella del host **antes** de enviar credenciales, ni (2) enviar/recibir bytes del PTY. Se amplía el trait sin tokio en `core`: la salida del PTY se entrega a un *sink* síncrono que la composition root conectará a un Tauri channel (T-15), nunca a React.

**Archivos a modificar:**
- `crates/core/src/ports.rs`
- `crates/core/src/port_errors.rs`

**Interfaces / firmas esperadas:**
```rust
/// Resultado del handshake: la conexión existe pero aún NO está autenticada.
pub struct Connected { pub id: ConnectionId, pub fingerprint: HostKeyFingerprint }

/// Receptor de la salida del PTY. Se invoca desde el adaptador; no debe bloquear.
#[cfg_attr(any(test, feature = "mocks"), mockall::automock)]
pub trait PtySink: Send + 'static {
    fn data(&mut self, bytes: &[u8]);
    fn closed(&mut self, exit_status: Option<u32>);
}

pub trait SshTransport: Send + Sync {
    fn connect(&self, host: &Host) -> impl Future<Output = Result<Connected, TransportError>> + Send;      // cambia
    fn authenticate(&self, conn: ConnectionId, credential: Credential) -> impl Future<Output = Result<(), TransportError>> + Send;
    fn open_pty(&self, conn: ConnectionId, size: PtySize, sink: Box<dyn PtySink>) -> impl Future<Output = Result<ChannelId, TransportError>> + Send;   // cambia
    fn write<'a>(&self, channel: ChannelId, bytes: &'a [u8]) -> impl Future<Output = Result<(), TransportError>> + Send;                          // nuevo
    fn resize(&self, channel: ChannelId, size: PtySize) -> impl Future<Output = Result<(), TransportError>> + Send;
    fn close(&self, conn: ConnectionId) -> impl Future<Output = Result<(), TransportError>> + Send;
}
```
- `TransportError`: añadir `NotConnected` (id desconocido o conexión cerrada) y `AuthenticationRejected` (el servidor rechazó la credencial; distinto de `Authentication` = fallo de protocolo). Mensajes literales sin datos variables.
- `PtySize::new(rows, cols) -> Result<PtySize, DomainError>` que rechaza 0 en cualquiera (`DomainError::InvalidPtySize`, nueva variante en `crates/core/src/error.rs` → **este archivo también se modifica**; total 3 archivos).

**Criterios de aceptación (verificables por test):**
- [ ] Tests de mockabilidad de T-08a actualizados a las nuevas firmas y en verde.
- [ ] Test nuevo: `MockSshTransport::open_pty` recibe un `Box<dyn PtySink>` y el test comprueba que el sink recibió `data(b"ok")` cuando el mock lo invoca.
- [ ] `MockPtySink` existe y verifica `closed(Some(0))`.
- [ ] `PtySize::new(0, 80)` y `(24, 0)` → `InvalidPtySize`; `(24, 80)` → Ok.
- [ ] `core` sigue sin tokio/tauri/I/O; opción B (sin `async-trait` ni `dyn` sobre `SshTransport`; `dyn PtySink` sí, es un trait síncrono).

**Tests requeridos:** unit.
