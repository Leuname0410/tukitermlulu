## T-18b: Implement the session management use cases with credential handling
**Fase:** F4  **Depende de:** T-18 · **ADR:** 004
**Contexto:** Crear, editar, duplicar y borrar sesiones, gestionando la **contraseña** en `SecretStore` (recordar, cambiar, olvidar). La **passphrase de llave nunca llega a estos casos de uso** (no hay parámetro para ella): se pide al conectar y vive solo en memoria por pestaña (T-17a). Las pestañas abiertas guardan una copia del destino al abrirse, así que editar una sesión solo afecta a la **próxima** conexión; la passphrase retenida de una pestaña abierta sigue correspondiendo a la llave con la que esa pestaña se conectó (no hay nada que invalidar aquí).

**Archivos a crear/modificar:**
- `crates/application/src/lib.rs` (modificar: `pub mod session_errors; pub mod edit_session; pub mod copy_delete_session;`)
- `crates/application/src/session_errors.rs` (crear: `SessionError`, `PasswordChange`, `SessionDraft`)
- `crates/application/src/edit_session.rs` (crear: `CreateSession`, `UpdateSession` + tests)
- `crates/application/src/copy_delete_session.rs` (crear: `DuplicateSession`, `DeleteSession` + tests)

**Interfaces / firmas esperadas:**

```rust
// session_errors.rs
#[derive(Debug, thiserror::Error)]
pub enum SessionError {
    #[error(transparent)] Domain(#[from] DomainError),
    #[error(transparent)] Repository(#[from] RepositoryError),
    #[error(transparent)] Secret(#[from] SecretError),
}
pub enum PasswordChange { Keep, Set(SecretString), Forget }       // sin Debug derivado que exponga el valor (Debug manual o ninguno)
pub struct SessionDraft { pub name: String, pub host: Host, pub auth: AuthMethod, pub folder: Option<FolderId> }

// edit_session.rs  (un struct por caso de uso, dependencias por constructor)
pub struct CreateSession<R: SessionRepository, S: SecretStore> { .. }
impl CreateSession { pub fn new(repo: R, secrets: S) -> Self;
    pub async fn execute(&self, draft: SessionDraft, password: Option<&SecretString>) -> Result<Session, SessionError>; }
pub struct UpdateSession<R, S> { .. }
impl UpdateSession { pub fn new(repo: R, secrets: S) -> Self;
    pub async fn execute(&self, session: &Session, password: PasswordChange) -> Result<(), SessionError>; }

// copy_delete_session.rs
pub struct DuplicateSession<R: SessionRepository> { .. }   // no recibe SecretStore: no puede copiar secretos
impl DuplicateSession { pub fn new(repo: R) -> Self; pub async fn execute(&self, id: SessionId) -> Result<Session, SessionError>; }
pub struct DeleteSession<R, S> { .. }
impl DeleteSession { pub fn new(repo: R, secrets: S) -> Self; pub async fn execute(&self, id: SessionId) -> Result<(), SessionError>; }
```

**Reglas:**
- `CreateSession`: id = `repo.next_session_id()`; `Session::new(..)`; `save_session`. Si `auth = Password { remember: true }` y llega contraseña → `secrets.set`. En cualquier otro caso no se toca `SecretStore`.
- `UpdateSession`: `get_session` (ausente → `Repository(NotFound)`) → `save_session(session)`. Después:
  - nuevo `auth` es `PublicKey` o `Password { remember: false }` → `secrets.delete` (cambiar a llave o dejar de recordar borra la contraseña guardada), sin importar `password`.
  - `Password { remember: true }`: `Set(p)` → `secrets.set(p)` (reemplaza); `Forget` → `secrets.delete`; `Keep` → nada.
- `DuplicateSession`: copia con id nuevo y nombre `"<nombre> (copia)"`, misma carpeta; **no** toca secretos (la copia pedirá la contraseña al conectar).
- `DeleteSession`: `delete_session` y luego `secrets.delete` de esa sesión.
- `SecretKey { session: id }` como clave. Ningún camino llama a `secrets.set` con algo que no sea la contraseña recibida.
- Tests con `mockall` (`MockSessionRepository`, `MockSecretStore`) y el `block_on` mínimo existente (sin runtime).

**Criterios de aceptación:**
- [ ] Crear con contraseña + recordar → `set` una vez con esa contraseña; crear sin recordar o con llave → `set` nunca se llama.
- [ ] Editar puerto/usuario con `Keep` → `save_session` con los nuevos valores y `SecretStore` intacto.
- [ ] `Set(nueva)` reemplaza la guardada (`set` con la nueva); `Forget` → `delete`.
- [ ] Cambiar de contraseña a llave → `delete`, aunque llegue `Set(..)`; `remember: false` → `delete`.
- [ ] Editar una sesión inexistente → `Repository(NotFound)` y no se guarda nada.
- [ ] Duplicar → id nuevo, nombre con " (copia)", mismos host/auth/carpeta; el tipo no tiene acceso a `SecretStore`.
- [ ] Borrar → `delete_session` y `secrets.delete` de esa sesión.
- [ ] Un error del `SecretStore` se propaga como `SessionError::Secret`; `format!("{err}")` nunca contiene la contraseña (test).
- [ ] `application` solo depende de `tuki-core` y `thiserror`. `just check` en verde.
