## T-33c: Release workflow on tags (includes T-33b without signing)
**Fase:** F7  **Depende de:** T-33a · **Decisiones:** D1 y D2 (sin firma en macOS ni en Windows)
**Contexto:**
- Al hacer push de un tag `v*`, GitHub Actions compila en los 3 SO y crea una release **en borrador** con los instaladores y un `SHA256SUMS.txt`.
- El README documenta cómo abrir la app sin firmar en macOS (Gatekeeper) y en Windows (SmartScreen).

**Archivos a crear/modificar:**
- `.github/workflows/release.yml` (crear)
- `README.md` (modificar: sección "Install" con las instrucciones)

**Reglas (`release.yml`):**
- `on: push: tags: ['v*']`.
- `permissions: contents: write`, **solo** en este workflow; `ci.yml` no se toca.
- Job `build` con la matriz:
  - `ubuntu-22.04` (AppImage + deb; glibc más antigua = más compatible);
  - `windows-latest` (nsis + msi);
  - `macos-latest` con `args: --target universal-apple-darwin` y `rustup target add aarch64-apple-darwin x86_64-apple-darwin`.
- Pasos del job `build`:
  - las mismas dependencias de Linux que `ci.yml`, más Node LTS con caché npm, `npm --prefix ui ci`, `dtolnay/rust-toolchain@stable` y `Swatinem/rust-cache@v2`;
  - luego `tauri-apps/tauri-action@v0` con `projectPath: crates/desktop`, `tauriScript: npm --prefix ../../ui run tauri` (o la forma equivalente que funcione con el layout), `tagName: ${{ github.ref_name }}`, `releaseName: tukitermlulu ${{ github.ref_name }}`, `releaseDraft: true`, `prerelease: false` y `args` por matriz.
- Job `checksums` (`needs: build`, `ubuntu-latest`):
  - `gh release download "$GITHUB_REF_NAME" --dir dist` (con `GH_TOKEN: ${{ github.token }}`);
  - `sha256sum` de todos los archivos a `SHA256SUMS.txt`;
  - `gh release upload "$GITHUB_REF_NAME" SHA256SUMS.txt --clobber`.
- Sin secretos de firma. Sin `updater`. Las acciones van fijadas a una versión mayor (`@v4`, `@v0`, `@v2`), como en `ci.yml`.
- `concurrency: release-${{ github.ref }}` sin cancelar en curso.

**README, sección "Install":**
- Descarga desde Releases y verificación con `sha256sum -c SHA256SUMS.txt` (o `Get-FileHash` en Windows).
- macOS: clic derecho → Abrir, o `xattr -dr com.apple.quarantine /Applications/tukitermlulu.app`, con la explicación de que la app no está notarizada.
- Windows: SmartScreen → "Más información" → "Ejecutar de todas formas"; la app no está firmada.
- Linux: `chmod +x *.AppImage`, o `sudo apt install ./tukitermlulu_*.deb`.

**Criterios de aceptación:**
- [ ] `release.yml` es YAML válido. El orquestador lo comprueba con `npx --yes yaml-lint` o equivalente; si hay `actionlint` disponible, sin errores.
- [ ] Ninguna otra parte del repo cambia salvo `README.md`; `ci.yml` queda intacto.
- [ ] `just check` en verde.
- [ ] (Humano) Push de un tag `v0.1.0-rc.1` → release en borrador con `.msi`, `-setup.exe`, `.AppImage`, `.deb`, `.dmg` y `SHA256SUMS.txt`.

**Commits:** `ci: release workflow on tags with checksums [T-33c]` y `docs: install instructions for unsigned builds [T-33c]`. Sin código de producción, así que no hay commit `test:`; la verificación es la validación de YAML y el tag rc.

**Fuera de alcance:** firma y notarización (D1/D2: no en v1), auto-update, Homebrew/winget.
