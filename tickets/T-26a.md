## T-26a: Add chmod and download-to-folder support for the SFTP context menu
**Fase:** F5  **Depende de:** T-25
**Contexto:** El menú contextual (T-26b) necesita cambiar permisos (servidores Unix) y descargar sin diálogo nativo: se descarga a la carpeta de **Descargas** del sistema (`app.path().download_dir()`), sin dependencias nuevas.

**Archivos a crear/modificar:**
- `crates/core/src/ports.rs` (modificar: `RemoteFileSystem::chmod(conn, path, mode: u32)`; `FileEntry`/`FileStat` ganan `permissions: Option<u32>`)
- `crates/adapters/src/sftp.rs` (modificar: `chmod` con `set_metadata`, solo los bits `0o7777`; `permissions` desde los atributos)
- `crates/adapters/tests/sftp.rs` (modificar: tests)
- `crates/desktop/src/sftp.rs` (modificar: `sftp_chmod(connection_id, path, mode)` (`mode > 0o7777` → `invalid_input`); `EntryDto.permissions`; `download_dir()` → comando `downloads_dir` para la UI)
- `ui/src/lib/api.ts` + `api.test.ts` (modificar: `sftpChmod`, `downloadsDir`, `EntryDto.permissions?: number`)

**Criterios de aceptación:**
- [ ] Integración: crear un archivo (subida de T-22a), `chmod 0o640` → `stat.permissions & 0o777 == 0o640`; `list` incluye los permisos.
- [ ] `chmod` de una ruta inexistente → `NotFound`.
- [ ] Rust unit: `mode` fuera de rango → `invalid_input`.
- [ ] UI: wrappers con argumentos camelCase.
- [ ] `just check` y `just test-int` en verde.

**Commits:** `test(adapters): sftp chmod and permissions [T-26a]` → `feat(adapters): sftp chmod and permissions [T-26a]`

**Fuera de alcance:** UI del menú (T-26b), chown, ACLs de Windows.
