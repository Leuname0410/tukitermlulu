## T-23b: Expose SFTP browsing commands in desktop and api.ts
**Fase:** F5  **Depende de:** T-23a
**Contexto:** Comandos para que el sidebar navegue el sistema de archivos remoto **sobre la conexión de la pestaña** (`connection_id`). También el directorio inicial de SFTP (`realpath(".")`, normalmente `$HOME`), porque el sidebar se abre automáticamente al conectar (decisión D1).

**Archivos a crear/modificar:**
- (prerrequisito, hecho en T-23a) `RemoteFileSystem::home(conn)` en core + adapter

- `crates/desktop/src/sftp.rs` (crear: DTOs y comandos)
- `crates/desktop/src/main.rs` (modificar: registrar comandos)
- `ui/src/lib/api.ts` + `ui/src/lib/api.test.ts` (modificar)

**Interfaces / firmas esperadas:**
```rust
#[derive(Serialize)] #[serde(rename_all = "camelCase")] pub struct EntryDto { name: String, path: String, is_dir: bool, size: u64 }
#[tauri::command] async fn sftp_home(state, connection_id: u64) -> Result<String, CommandError>;
#[tauri::command] async fn sftp_list(state, connection_id: u64, path: String) -> Result<Vec<EntryDto>, CommandError>;   // carpetas primero, luego por nombre
#[tauri::command] async fn sftp_mkdir(state, connection_id: u64, path: String) -> Result<(), CommandError>;
#[tauri::command] async fn sftp_rename(state, connection_id: u64, from: String, to: String) -> Result<(), CommandError>;
#[tauri::command] async fn sftp_remove(state, connection_id: u64, path: String) -> Result<(), CommandError>;
```
- Las rutas se validan con `RemotePath::new` (error → `invalid_input`). `FsError` → `not_found` / `permission_denied` / `io`.
- `api.ts`: `sftpHome`, `sftpList`, `sftpMkdir`, `sftpRename`, `sftpRemove` con validación de la respuesta, sin `any`.

**Criterios de aceptación:**

- [ ] Rust unit: orden carpetas-primero; mapeo de `FsError`; ruta vacía → `invalid_input`.
- [ ] UI: wrappers con argumentos camelCase; `sftpList` rechaza respuestas mal formadas.
- [ ] `just check` y `just test-int` en verde.

**Tests requeridos:** unit + Vitest.
**Commits:** `test(desktop): sftp browsing commands [T-23b]` → `feat(desktop): sftp browsing commands [T-23b]`

**Fuera de alcance:** UI del sidebar (T-23c), chmod y copiar ruta (T-26).
