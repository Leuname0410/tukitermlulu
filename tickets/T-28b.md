## T-28b: Detect the remote shell and build the per-shell integration line
**Fase:** F6  **Depende de:** T-28a · **ADR:** 006
**Contexto:** Antes de inyectar nada hay que saber qué shell tiene el usuario. Se ejecuta una sonda por un canal `exec` aparte, que nunca toca la terminal del usuario. Con su salida se clasifica la shell y se genera la línea de integración, que emite OSC 7 en cada prompt y al final el marcador `ESC ] 777 ; tuki-ready BEL`. Clasificar y generar son funciones puras en `application`. El `exec` es un método nuevo del puerto SSH.

**Archivos a crear/modificar:**
- `crates/core/src/ports.rs` (modificar: `SshTransport::exec(conn, command: &str) -> Result<ExecOutput, TransportError>`; `pub struct ExecOutput { pub stdout: Vec<u8>, pub stderr: Vec<u8>, pub status: Option<u32> }`)
- `crates/adapters/src/ssh_transport.rs` (modificar: `exec` = canal de sesión + `exec(true, cmd)`, recoger stdout/stderr hasta Close, tope de 64 KiB por flujo (lo que sobre se descarta), timeout de 5 s → `TransportError::Io`)
- `crates/adapters/tests/ssh_transport.rs` (modificar: tests de `exec`)
- `crates/application/src/shell_integration.rs` (crear: `ShellKind`, `PROBE_COMMAND`, `classify`, `integration_line` + tests)
- `crates/application/src/lib.rs` (modificar)

**Interfaces / firmas esperadas (`shell_integration.rs`):**
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum ShellKind { Bash, Zsh, Fish, PowerShell, Cmd, Unknown }
pub const PROBE_COMMAND: &str = "echo %COMSPEC%::$PSVersionTable::$0::$SHELL";
pub fn classify(output: &ExecOutput) -> ShellKind;
pub fn integration_line(shell: ShellKind) -> Option<String>;   // Unknown → None; termina en "\r" (Enter)
pub const READY_MARKER: &[u8] = b"\x1b]777;tuki-ready\x07";
```
**Reglas de `classify` (stdout + stderr en minúsculas):**
- Contiene `cmd.exe` y no contiene `::$0` literal → `Cmd`.
- `%comspec%` literal y aparece `psversion` o `system.collections.hashtable` → `PowerShell`.
- Stderr con `fish:` → `Fish`.
- `$0`/`$SHELL` acaba en `zsh` → `Zsh`; en `bash` → `Bash`.
- Cualquier otro caso (incluidos `sh`, `ash`, `dash`, `csh`) → `Unknown`.

**Reglas de `integration_line`** (una sola línea; empieza con espacio en las POSIX; incluye una primera emisión inmediata de OSC 7, y al final `printf '\r\033[K'` más el marcador):
- **Bash:**
  - define `__tuki_osc7` (`printf '\033]7;file://%s%s\007' "${HOSTNAME:-}" "$PWD"`);
  - la añade a `PROMPT_COMMAND` sin perder el existente;
  - hace `history -d $((HISTCMD-1)) 2>/dev/null`.
- **Zsh:**
  - `setopt HIST_IGNORE_SPACE`;
  - define la función y la añade a `precmd_functions+=(__tuki_osc7)`.
- **Fish:** `function __tuki_osc7 --on-variable PWD; printf '\e]7;file://%s%s\a' (hostname) $PWD; end`, y la llama una vez.
- **PowerShell:**
  - guarda `$function:prompt` y define un `global:prompt` que escribe `ESC]7;file:///` + ruta con `/` + `BEL` y luego llama al prompt original;
  - borra la línea del historial con `Clear-History -Count 1 -Newest`.
- **Cmd:** `prompt $E]7;file:///$P$E\$P$G`. Luego el marcador, con `echo` y `$E`, mediante `prompt` temporal o un `echo` equivalente.
- Ninguna línea contiene datos del usuario, porque se construyen a partir de constantes.

**Criterios de aceptación:**
- [ ] `classify` con salidas reales capturadas para cada caso (se meten como fixtures de texto en el test): bash, zsh, fish (stderr), pwsh, cmd, ash → Unknown.
- [ ] `integration_line`:
  - para Bash, Zsh y Fish contiene `]7;file://`, el marcador `]777;tuki-ready`, empieza con espacio y termina en `\r`;
  - para PowerShell y Cmd contiene `]7;file:///` y el marcador;
  - para Unknown → `None`.
- [ ] Integración (`just test-int`): `exec(conn, "echo hola")` → stdout `hola\n`, status 0; `exec` de un comando inexistente → status ≠ 0; `exec(conn, PROBE_COMMAND)` contra el contenedor (shell `ash`) → `classify` = `Unknown`.
- [ ] Un `exec` cuya salida supera 64 KiB no crece más allá del tope.
- [ ] Los mocks de `SshTransport` siguen compilando. `just check` y `just test-int` en verde.
