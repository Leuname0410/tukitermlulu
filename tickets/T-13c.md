## T-13c: Implement the PTY channel in the russh transport
**Fase:** F3  **Depende de:** T-13b
**Contexto:** Adaptador `SshTransport` (parte 2): abrir PTY + shell, bombear la salida al `PtySink` desde una tarea Tokio, escribir entrada, redimensionar y cerrar. Criterio del plan: `echo ok` devuelve `ok`.

**Archivos a modificar:**
- `crates/adapters/src/ssh_transport.rs`
- `crates/adapters/tests/ssh_transport.rs`

**Interfaces / comportamiento esperado:**
- `open_pty(conn, size, sink)`: `channel_open_session` → `request_pty(false, "xterm-256color", cols, rows, 0, 0, &[])` → `request_shell(false)`; guarda el lado de escritura del canal en un mapa `ChannelId → ...`; `tokio::spawn` de una tarea que hace `channel.wait()` en bucle: `Data` → `sink.data`, `ExitStatus` → recuerda el código, `Eof`/`Close`/`None` → `sink.closed(status)` y fin (elimina la entrada del mapa).
- `write(channel, bytes)`: envía los bytes tal cual (sin copiar a ningún estado intermedio); canal inexistente → `NotConnected`.
- `resize(channel, size)`: `window_change(cols, rows, 0, 0)`.
- `close(conn)`: cierra canales de esa conexión y desconecta; las tareas terminan llamando `closed`.
- La tarea nunca bloquea: el `PtySink` es síncrono y debe ser barato (documentarlo en un comentario).

**Criterios de aceptación (verificables por test de integración):**
- [ ] Tras autenticar con `ed25519`, `open_pty` + `write(b"echo ok\n")` → el sink recibe bytes que contienen `ok` en < 5 s.
- [ ] `write(b"exit\n")` → el sink recibe `closed(Some(0))`.
- [ ] `resize` a 40×120 y luego `write(b"stty size\n")` → la salida contiene `40 120`.
- [ ] `write` sobre un canal cerrado → `NotConnected`.
- [ ] `close(conn)` con un PTY abierto → el sink recibe `closed(..)`.
- [ ] `just test-int` y `just check` en verde.

**Tests requeridos:** integración (feature `integration`); el sink de test acumula en un `Arc<Mutex<Vec<u8>>>` + `tokio::sync::Notify`.
**Commits:** `test(adapters): pty echo, resize and exit tests [T-13c]` → `feat(adapters): russh pty channel with sink output [T-13c]`

**Fuera de alcance:** casos de uso, Tauri channels (T-15), reconexión (T-17), OSC 7 (T-27).
