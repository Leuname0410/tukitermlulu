## T-24a: Upload by dropping files from the OS onto the SFTP sidebar
**Fase:** F5  **Depende de:** T-23c
**Contexto:** Arrastrar archivos desde el explorador del SO (Explorer, Finder, gestor de Linux) al sidebar los sube a la carpeta que muestra el sidebar, encolándolos en la cola de T-22c. Tauri 2 entrega las rutas locales por `getCurrentWebview().onDragDropEvent` (el `drop` HTML5 no trae rutas). Sin dependencias nuevas.

**Archivos a crear/modificar:**
- `ui/src/lib/api.ts` (modificar: `onFileDrop(listener: (event: FileDropEvent) => void): Promise<() => void>` que envuelve `onDragDropEvent`; `FileDropEvent = { kind: "over"; x: number; y: number } | { kind: "drop"; paths: string[]; x: number; y: number } | { kind: "leave" }`)
- `ui/src/lib/api.test.ts` (modificar)
- `ui/src/sftp/useFileDrop.ts` (crear: hook que decide si el drop cae dentro del sidebar con `getBoundingClientRect` y llama a `enqueueUpload` por archivo)
- `ui/src/sftp/SftpSidebar.tsx` (modificar: resaltar la zona al pasar por encima (`data-drop-active` + texto accesible "Soltar para subir"); refrescar al terminar las subidas de esa carpeta)
- `ui/src/sftp/sftp.test.tsx` (modificar)

**Reglas:**
- Solo cuenta el drop cuyas coordenadas caen dentro del sidebar de la pestaña activa (con varias pestañas, solo la visible).
- Coordenadas: Tauri las da en píxeles físicos; se convierten con `window.devicePixelRatio` (función pura con test).
- Cada ruta → `enqueueUpload(connectionId, path, currentPath)`; los errores por archivo se muestran sin detener el resto.
- Directorios soltados: se ignoran con aviso "Las carpetas aún no se pueden subir" (recursivo fuera de alcance).
- Al recibir `onTransfers` con alguna subida `done` cuyo destino es la carpeta actual → `sftpList` de nuevo (como mucho 1 vez por segundo).

**Criterios de aceptación (Vitest, mocks de `../lib/api`):**
- [ ] Drop dentro del sidebar con 2 rutas → 2 `enqueueUpload` con la carpeta actual; fuera del sidebar → ninguno.
- [ ] La conversión de píxeles físicos a CSS respeta `devicePixelRatio` 1 y 2.
- [ ] `over` activa el resaltado y `leave` lo quita.
- [ ] Un `enqueueUpload` rechazado muestra el error y los demás siguen.
- [ ] Una subida `done` en la carpeta actual provoca un refresco.
- [ ] `just check` en verde.
- [ ] (Manual, humano) arrastrar desde Explorer (Windows), Finder (macOS) y el gestor de archivos de Linux.

**Commits:** `test(ui): drop files to upload [T-24a]` → `feat(ui): upload by dropping files on the sftp sidebar [T-24a]`

**Fuera de alcance:** arrastrar del sidebar al SO (T-24b, pendiente de decisión), subir carpetas, barra de progreso (T-26b).
