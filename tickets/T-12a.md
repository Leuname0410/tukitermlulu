## T-12a: Add the KeyFileStore port and the ImportKey use case
**Fase:** F2  **Depende de:** T-11
**Contexto:** Importar una llave a la app: se valida que sea una llave legible y, opcionalmente, se copia al directorio privado de la app. Requiere un puerto nuevo (`KeyFileStore`) porque `application` no puede tocar el sistema de archivos. Primer caso de uso del proyecto: fija el patrón (struct + `execute`, puertos genéricos, opción B).

**Archivos a crear/modificar:**
- `crates/core/src/ports.rs` (modificar: añadir el puerto `KeyFileStore`)
- `crates/application/Cargo.toml` (modificar: `[dev-dependencies] tuki-core = { path = "../core", features = ["mocks"] }`, `mockall = "0.13"`)
- `crates/application/src/lib.rs` (modificar: `pub mod import_key;`)
- `crates/application/src/import_key.rs` (crear: caso de uso + tests unitarios)

**Interfaces / firmas esperadas:**
```rust
// core/src/ports.rs
#[cfg_attr(any(test, feature = "mocks"), mockall::automock)]
pub trait KeyFileStore: Send + Sync {
    /// Copia la llave al directorio privado de la app y devuelve la nueva referencia.
    fn import<'a>(&self, source: &'a KeyRef) -> impl Future<Output = Result<KeyRef, KeyError>> + Send;
}
// application/src/import_key.rs
pub struct ImportKey<L: KeyLoader, S: KeyFileStore> { loader: L, store: S }
pub struct ImportKeyRequest<'a> { pub source: KeyRef, pub copy_to_app_dir: bool, pub passphrase: Option<&'a SecretString> }
pub struct ImportedKey { pub key: KeyRef, pub has_passphrase: bool }
impl<L: KeyLoader, S: KeyFileStore> ImportKey<L, S> {
    pub fn new(loader: L, store: S) -> Self;
    pub async fn execute(&self, request: ImportKeyRequest<'_>) -> Result<ImportedKey, KeyError>;
}
```
Reglas de `execute`:
1. `loader.load(&source, passphrase)`: `Ok` → `has_passphrase = passphrase.is_some()`; `PassphraseRequired` sin passphrase → la llave es válida y está cifrada (`has_passphrase = true`, se continúa); cualquier otro error → se devuelve tal cual.
2. La llave cargada se suelta de inmediato (no se retiene).
3. Si `copy_to_app_dir` → `store.import(&source)` y el `KeyRef` devuelto reemplaza al original; si no, se conserva `source`. Si `import` falla, no hay efectos parciales que limpiar en este caso de uso.

**Criterios de aceptación (verificables por test con mocks):**
- [ ] Llave válida sin copia → devuelve `source`, `has_passphrase = false`, `import` no se llama.
- [ ] Llave válida con copia → devuelve el `KeyRef` del store; `import` se llama una vez.
- [ ] `PassphraseRequired` sin passphrase → Ok con `has_passphrase = true`.
- [ ] `WrongPassphrase` / `UnsupportedFormat` / `NotFound` → error propagado e `import` no se llama.
- [ ] Error de `import` → se propaga.
- [ ] `application` solo depende de `tuki-core` (sin tokio en `[dependencies]`); tests con un `block_on` mínimo como el de `core` (sin runtime).

**Tests requeridos:** unit con `mockall`.
**Commits:** `test(app): import key use case [T-12a]` → `feat(app): import key use case and key file store port [T-12a]`

**Fuera de alcance:** adaptador de `KeyFileStore` (T-12b), UI, persistencia de la sesión.
