## T-27: Implement the OSC 7 CwdTracker over the PTY byte stream
**Fase:** F6  **Depende de:** T-21 (independiente de la UI; puede ir en paralelo con F5)
**Contexto:** Las shells con integración emiten `ESC ] 7 ; file://<host>/<ruta> BEL` (o terminado en `ESC \`) cada vez que cambia el directorio. El tracker observa los bytes que van a xterm **sin modificarlos** (xterm ignora OSC 7) y devuelve el último directorio visto. Es lógica pura: sin I/O ni tokio.

**Archivos a crear/modificar:**
- `crates/adapters/src/cwd_tracker.rs` (crear: `Osc7Tracker` + tests unitarios)
- `crates/adapters/src/lib.rs` (modificar: `pub mod cwd_tracker;`)

**Interfaces / firmas esperadas:**
```rust
#[derive(Default)]
pub struct Osc7Tracker { state: State, buffer: Vec<u8> }     // máquina de estados: Ground → Esc → OscStart ('7') → Semicolon → Payload → (BEL | ESC '\')
impl Osc7Tracker { pub fn new() -> Self; }
impl CwdTracker for Osc7Tracker { fn feed(&mut self, bytes: &[u8]) -> Option<RemotePath>; }   // la última ruta válida completada en este fragmento
const MAX_PAYLOAD: usize = 4096;   // si se supera, se descarta la secuencia y se vuelve a Ground
```
**Reglas:**
- Solo `file://` como esquema; el host se ignora (`file:///tmp` y `file://srv/tmp` → `/tmp`).
- Se decodifica `%XX` (UTF-8); una secuencia mal formada o no UTF-8 se descarta sin error.
- El resultado se construye con `RemotePath::new`; si lo rechaza, se descarta.
- Las secuencias partidas entre llamadas a `feed` (incluso `ESC` al final de un fragmento y `\` al principio del siguiente) se reconstruyen.
- Otras secuencias OSC (`ESC ] 0 ;` título, etc.) se ignoran sin afectar al estado.
- Sin `unwrap`/`expect`/indexado sin chequear.

**Criterios de aceptación (unit):**
- [ ] `ESC]7;file://host/home/tuki BEL` → `/home/tuki`; con terminador `ESC \` → igual.
- [ ] Partida en 2 y en 3 fragmentos (cortes dentro del prefijo, del payload y del terminador) → mismo resultado, y `None` en los fragmentos intermedios.
- [ ] Dos secuencias en el mismo fragmento → devuelve la última.
- [ ] `%20` y UTF-8 (`/tmp/caf%C3%A9`) se decodifican.
- [ ] OSC 0 (título), texto normal y `ESC [` (CSI) → `None` y no rompen una OSC 7 posterior.
- [ ] Payload > 4096 bytes → descartado; la siguiente secuencia válida se reconoce.
- [ ] Esquema distinto de `file://` o `%` inválido → `None`.
- [ ] `just check` en verde.

**Tests requeridos:** unit (≥ 10).
**Commits:** `test(adapters): osc 7 cwd tracker [T-27]` → `feat(adapters): osc 7 cwd tracker [T-27]`

**Fuera de alcance:** cablear el tracker en el `ChannelSink` y emitir el cwd a la UI (T-28), rutas de Windows (T-30).
