## T-11: Implement the TOFU HostKeyVerifier over an app-owned known_hosts file
**Fase:** F2  **Depende de:** T-10
**Contexto:** Verificación de la llave del host con TOFU sobre un archivo propio (no el `~/.ssh/known_hosts` del usuario). Entradas por `[host]:puerto`: el mismo host con otro puerto es un host nuevo. El bloqueo ante `Changed` lo hace el caso de uso (T-14); este adaptador solo informa y persiste.

**Archivos a crear/modificar:**
- `crates/adapters/Cargo.toml` (modificar: features de `tokio` + `"fs"`; `[dev-dependencies] tempfile = "3"`)
- `crates/adapters/src/lib.rs` (modificar: `pub mod known_hosts;`)
- `crates/adapters/src/known_hosts.rs` (crear)
- `crates/adapters/tests/known_hosts.rs` (crear)

**Interfaces / firmas esperadas:**
```rust
pub struct FileHostKeyVerifier { path: PathBuf }      // new(path: impl Into<PathBuf>): la ruta la decide la composition root
impl tuki_core::ports::HostKeyVerifier for FileHostKeyVerifier { .. }
```
- Formato de línea: `[<hostname en minúsculas>]:<puerto> <fingerprint>` (`SHA256:...`). Líneas vacías o que empiecen por `#` se ignoran; líneas malformadas se ignoran (no rompen la verificación de las demás).
- `verify`: archivo inexistente → `Unknown`; misma huella → `Known`; otra huella para la misma clave → `Changed`.
- `trust`: añade la entrada o **reemplaza** la existente de esa clave; escritura atómica (archivo temporal en el mismo directorio + `rename`); crea el directorio padre si falta. Async con `tokio::fs`.
- Fingerprint sin prefijo `SHA256:` → `HostKeyError::InvalidFingerprint` en `verify` y `trust` (endurece el MINOR de T-08b sin tocar `core`).

**Criterios de aceptación (verificables por test, en `tempfile::tempdir()`):**
- [ ] Host nuevo → `Unknown`; tras `trust` → `Known`.
- [ ] Misma clave con huella distinta → `Changed`.
- [ ] Mismo host, otro puerto → `Unknown` aunque el otro puerto sea `Known`.
- [ ] Hostname en mayúsculas/minúsculas resuelve a la misma entrada.
- [ ] `trust` sobre una entrada `Changed` la reemplaza (queda una sola línea para esa clave).
- [ ] Comentarios y líneas malformadas no afectan al resultado.
- [ ] Huella sin `SHA256:` → `InvalidFingerprint`.

**Fuera de alcance:** importar el `~/.ssh/known_hosts` del usuario, hashed hosts, cálculo de la huella desde la llave (T-13), UI (T-20).
