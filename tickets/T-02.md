## T-02: Add the justfile with the `check` quality gate
**Fase:** F0  **Depende de:** T-01d
**Contexto:** `just check` es el gate obligatorio de cada ticket: fmt, clippy, test, audit, deny (Rust) + eslint, typecheck, vitest, npm audit (UI). Debe quedar en verde sobre el scaffold actual (sin tests todavía).

**Archivos a crear/modificar:**
- `justfile` (crear)
- `deny.toml` (crear)
- `ui/eslint.config.js` (crear)
- `ui/package.json` (modificar)
- `.gitignore` (modificar: añadir `crates/desktop/gen/`)
(+ `ui/package-lock.json` generado)

**Estructura esperada:**
- `justfile`:
  - `set windows-shell := ["powershell.exe", "-NoLogo", "-NoProfile", "-Command"]`
  - `export TAURI_APP_PATH := justfile_directory() / "crates/desktop"`
  - `default` → `just --list`.
  - `dev` → `npm --prefix ui run tauri dev`.
  - `check` → en este orden, abortando al primer fallo:
    `cargo fmt --all -- --check`,
    `cargo clippy --workspace --all-targets -- -D warnings`,
    `cargo test --workspace`,
    `cargo audit`,
    `cargo deny check`,
    `npm --prefix ui run lint`,
    `npm --prefix ui run typecheck`,
    `npm --prefix ui run test`,
    `npm --prefix ui audit --audit-level=high`.
  - Nada más (`test-int` llega en T-05, `e2e` en T-31).
- `deny.toml` (formato de `cargo-deny` 0.18+):
  - `[licenses]` allow: `MIT`, `Apache-2.0`, `Apache-2.0 WITH LLVM-exception`, `MPL-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Unicode-3.0`, `Zlib`, `CC0-1.0`. Añade otra licencia solo si un crate del lockfile la exige y es permisiva/débil-copyleft; nunca GPL/AGPL. Lista en la Entrega las que añadiste.
  - `[bans] multiple-versions = "warn"`, `wildcards = "deny"` (los path deps internos permitidos: `allow-wildcard-paths = true`; si hace falta, añade `publish = false` **no**: no toques los `Cargo.toml` de los crates, usa la opción de deny).
  - `[advisories]` por defecto (sin `ignore`).
  - `[sources] unknown-registry = "deny"`, `unknown-git = "deny"`.
- `ui/package.json`:
  - scripts: `"lint": "eslint ."`, `"typecheck": "tsc --noEmit"`, `"test": "vitest run --passWithNoTests"`.
  - devDependencies: `eslint`, `@eslint/js`, `typescript-eslint`, `eslint-plugin-react-hooks`, `globals`, `vitest` (últimas estables compatibles).
  - Si `typescript-eslint` no soporta la versión de `typescript` instalada, fija `typescript` a la última versión que sí soporte y dilo en la Entrega.
- `ui/eslint.config.js` (flat config): ignora `dist/`; `@eslint/js` recommended + `typescript-eslint` `strict` + `react-hooks` recommended; `@typescript-eslint/no-explicit-any: "error"`; globals de browser.

**Criterios de aceptación (verificables):**
- [ ] `just check` termina en verde (exit 0) en Windows.
- [ ] Introducir temporalmente un `any` en `ui/src/main.tsx` hace fallar `npm --prefix ui run lint` (verificación manual; no se commitea).
- [ ] `cargo deny check` en verde con `deny.toml`, sin `ignore` de advisories.
- [ ] `git status` limpio tras `just dev`/build (`crates/desktop/gen/` ignorado).

**Tests requeridos:** ninguno (infraestructura; Vitest corre con `--passWithNoTests`).
**Commit:** `build: add justfile quality gate and cargo-deny config [T-02]`

**Nota (gate intento 1):** `rust-version = "1.85"` del `Cargo.toml` raíz hace que el resolver retenga `time 0.3.45` y `quick-xml 0.38.4` (vulnerables). Permitido: subir `rust-version` a `"1.100"` (toolchain estable actual) en `Cargo.toml` raíz y ejecutar `cargo update` (solo lockfile, dentro de semver). `publish = false` en los manifiestos (para `allow-wildcard-paths`) queda aceptado.

**Fuera de alcance:** CI, Prettier, Testing Library/jsdom, lints de clippy adicionales, cambios en crates o en código de `ui/src`, recetas `test-int`/`e2e`.
