## T-07b: Add the AuthMethod, KeyRef, Session and Folder entities
**Fase:** F1  **Depende de:** T-07a
**Contexto:** Entidades del gestor de sesiones. Ningún secreto vive en estas entidades: solo referencias (la passphrase/contraseña va al `SecretStore`, T-10).

**Archivos a crear/modificar:**
- `crates/core/src/lib.rs` (modificar: `pub mod auth; pub mod session;`)
- `crates/core/src/error.rs` (modificar: variantes nuevas)
- `crates/core/src/auth.rs` (crear)
- `crates/core/src/session.rs` (crear)

**Interfaces / firmas esperadas:**
```rust
// error.rs (nuevas variantes)
#[error("key path must not be empty")] EmptyKeyPath,
#[error("name must not be empty")] EmptyName,
#[error("a folder cannot be its own parent")] FolderCycle,
// auth.rs
pub struct KeyRef { path: String }  // ruta local al archivo de llave; impl KeyRef { pub fn new(path: &str) -> Result<Self, DomainError>; pub fn path(&self) -> &str; }
pub enum AuthMethod { Password { remember: bool }, PublicKey { key: KeyRef, has_passphrase: bool } }
// `remember` = la contraseña se guarda en SecretStore (T-10/T-18b). La passphrase de llave NUNCA se guarda: se pide en cada conexión.
// session.rs
pub struct SessionId(u64); pub struct FolderId(u64);   // ids opacos; impl new(u64) + get()
pub struct Folder  { pub id: FolderId, pub name: String, pub parent: Option<FolderId> }
pub struct Session { pub id: SessionId, pub name: String, pub host: Host, pub auth: AuthMethod, pub folder: Option<FolderId> }
impl Folder  { pub fn new(id: FolderId, name: &str, parent: Option<FolderId>) -> Result<Self, DomainError>; }
impl Session { pub fn new(id: SessionId, name: &str, host: Host, auth: AuthMethod, folder: Option<FolderId>) -> Result<Self, DomainError>; }
```
Derivar `Debug, Clone, PartialEq, Eq` (+ `Copy, Hash` en los ids). Nombres con `trim`.

**Criterios de aceptación (verificables por test):**
- [ ] `KeyRef::new("")` → `EmptyKeyPath`.
- [ ] `Folder::new` con nombre vacío → `EmptyName`; con `parent == Some(id)` → `FolderCycle`.
- [ ] `Session::new` con nombre vacío/espacios → `EmptyName`; con datos válidos → Ok y nombre recortado.
- [ ] Ningún tipo contiene campos de contraseña/passphrase: `AuthMethod` solo lleva el flag `remember` (contraseña) y `has_passphrase` (revisión + test).
- [ ] No existe forma de representar "recordar passphrase" en el dominio (revisión).
- [ ] Una `Session` es editable: `with_host(Host)`, `with_auth(AuthMethod)`, `rename(&str) -> Result` devuelven una sesión nueva validada (test: cambiar puerto/usuario conserva `id`).

**Tests requeridos:** unit en cada archivo.
**Commits:** `test(core): session and auth invariants [T-07b]` → `feat(core): session, folder and auth entities [T-07b]`

**Fuera de alcance:** persistencia, serde, detección de ciclos profundos en el árbol (repositorio, T-18), secretos.
