## T-12b: Implement the filesystem KeyFileStore with private permissions
**Fase:** F2  **Depende de:** T-12a
**Contexto:** Copia una llave al directorio privado de la app con permisos solo del usuario. En Unix: directorio 0700 y archivo 0600. En Windows: el directorio lo decide la composition root dentro de `%APPDATA%` (ACL del perfil, heredada solo por el usuario, SYSTEM y Administradores); este ticket **no** añade dependencias de ACL (ver nota).

**Archivos a crear/modificar:**
- `crates/adapters/src/lib.rs` (modificar: `pub mod key_file_store;`)
- `crates/adapters/src/key_file_store.rs` (crear)
- `crates/adapters/tests/key_file_store.rs` (crear)

**Interfaces / firmas esperadas:**
```rust
pub struct FsKeyFileStore { dir: PathBuf }   // new(dir: impl Into<PathBuf>)
impl tuki_core::ports::KeyFileStore for FsKeyFileStore { .. }
```
- Crea `dir` si no existe (Unix: `0o700`).
- Nombre destino: el nombre de archivo original; si ya existe uno **con contenido distinto**, añade sufijo `-1`, `-2`… (nunca sobrescribe). Si existe con el mismo contenido, reutiliza la ruta (idempotente).
- Escritura: archivo temporal en `dir` creado con `0o600` (Unix, vía `OpenOptions` + `mode`) → copiar → `rename`. Nunca un instante con permisos más abiertos.
- Origen sin nombre de archivo o inexistente → `KeyError::NotFound`; resto de I/O → `KeyError::Io`. El mensaje no incluye rutas.
- `tokio::fs` (async). El contenido leído se mantiene en `Zeroizing<Vec<u8>>`.

**Criterios de aceptación (verificables por test, en `tempfile::tempdir()`):**
- [ ] Importar copia el contenido byte a byte y devuelve un `KeyRef` dentro de `dir`.
- [ ] `#[cfg(unix)]`: el archivo queda `0o600` y el directorio `0o700`.
- [ ] Importar dos veces la misma llave → misma ruta (no duplica).
- [ ] Otra llave con el mismo nombre → sufijo `-1`; la primera no se modifica.
- [ ] Origen inexistente → `NotFound`.

**Tests requeridos:** integración (`#[tokio::test]` + `tempfile`). En CI corre en los 3 SO (la parte `cfg(unix)` en Linux/macOS).
**Commits:** `test(adapters): key file store tests [T-12b]` → `feat(adapters): private filesystem key file store [T-12b]`

**Nota (decisión a validar por el humano):** ACL explícita en Windows requeriría el crate `windows` (dependencia fuera del plan). Se propone confiar en la ACL heredada de `%APPDATA%` y documentarlo en el ADR de secretos.

**Fuera de alcance:** borrar llaves importadas, UI, ACL explícita en Windows.
