## T-19: Add the session tree, search and session form in the UI
**Fase:** F4  **Depende de:** T-18c
**Contexto:** Barra lateral estilo MobaXterm: árbol de carpetas y sesiones, búsqueda, y crear/editar/duplicar/borrar. Doble clic (o Enter) sobre una sesión abre una pestaña conectada **por `sessionId`** (T-18c), así "recordar contraseña" usa el keyring. El formulario **nunca** muestra ni prellena un secreto guardado: solo indica "Contraseña guardada".

- `ui/src/sessions/sessionTree.ts` (crear: lógica pura — construir el árbol y filtrar)
- `ui/src/sessions/SessionTree.tsx` (crear: árbol + búsqueda + acciones)
- `ui/src/sessions/SessionForm.tsx` (crear: formulario de crear/editar)
- `ui/src/sessions/sessions.test.tsx` (crear)
- `ui/src/App.tsx` (modificar: barra lateral con `SessionTree`; `QuickConnect` se mantiene; abrir pestaña desde una sesión)

**Interfaces / firmas esperadas:**
```ts
// sessionTree.ts
export interface TreeNode { folder: FolderDto | null; folders: TreeNode[]; sessions: SessionDto[] }   // raíz: folder null
export function buildTree(folders: readonly FolderDto[], sessions: readonly SessionDto[]): TreeNode;  // padre inexistente → a la raíz; orden alfabético
export function filterTree(tree: TreeNode, query: string): TreeNode;   // coincide nombre, host o usuario (sin mayúsculas/acentos); conserva las carpetas ancestro; query vacía → árbol entero
export function sessionTarget(session: SessionDto): ConnectTarget;      // incluye sessionId

// SessionForm.tsx
export interface SessionFormProps { initial?: SessionDto; folders: readonly FolderDto[];
  onSubmit(input: SessionInput, password: PasswordInput): Promise<void>; onCancel(): void }
export function SessionForm(props: SessionFormProps): JSX.Element;
```

**Formulario:**
- Campos: nombre, host, puerto (1–65535, por defecto 22), usuario, carpeta (select), método (contraseña | llave).
- Contraseña: `<input type="password">` vacío siempre; casilla "Recordar contraseña". En edición, si `passwordSaved`, texto "Contraseña guardada" y botón "Olvidar contraseña guardada" → `{ kind: "forget" }`. Campo vacío = `{ kind: "keep" }`; con valor = `{ kind: "set", value }`. Al crear: `password` solo si "recordar" está marcado.
- Llave: ruta de la llave + casilla "La llave tiene passphrase". **No hay campo de passphrase.**
- Validación en cliente (mismas reglas del dominio: nombre/host/usuario no vacíos tras `trim`, puerto 1–65535, ruta no vacía con llave); el botón Guardar se deshabilita si no es válido. Un `CommandError` `invalid_input` del backend se muestra junto al formulario.
- El valor de la contraseña se borra del estado local tras enviar.

**Árbol:**
- `role="tree"` / `role="treeitem"` con `aria-expanded` en carpetas; búsqueda con `<input type="search" aria-label="Buscar sesiones">`.
- Acciones por sesión (menú o botones con `aria-label`): Conectar, Editar, Duplicar, Borrar (con `confirm` nativo). Acciones de carpeta: Nueva carpeta, Renombrar, Borrar.
- Tras cada mutación se recarga con `listSessions` + `listFolders` (sin caché). Toda la lógica de árbol/filtro en `sessionTree.ts`, no en el JSX.

**Criterios de aceptación (Vitest + Testing Library por rol/etiqueta, `vi.mock("../lib/api")`):**
- [ ] `buildTree`/`filterTree`: anidado, orden, huérfanos a la raíz, búsqueda por host y sin acentos conserva ancestros.
- [ ] Crear sesión con contraseña recordada → `createSession(input, password)`; sin recordar → sin contraseña.
- [ ] Editar con el campo vacío → `{ kind: "keep" }`; con valor → `set`; "Olvidar" → `forget`.
- [ ] En edición con `passwordSaved: true` el campo de contraseña está vacío y se ve "Contraseña guardada".
- [ ] Método llave: no existe ningún campo etiquetado "Passphrase".
- [ ] Puerto 0 o host vacío deshabilitan Guardar.
- [ ] Duplicar y Borrar llaman a la API y recargan la lista.
- [ ] Conectar una sesión abre una pestaña y `api.connect` recibe `sessionId`.
- [ ] `just check` en verde.
