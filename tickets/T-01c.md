## T-01c: Scaffold the React + TypeScript + Vite UI
**Fase:** F0  **Depende de:** T-01b
**Contexto:** Tercera parte del scaffold: frontend mínimo en `ui/` que luego servirá la ventana Tauri (T-01d). Sin Tailwind, Zustand, ESLint ni Vitest todavía (llegan en T-02 o en tickets de UI).

**Archivos a crear:**
- `ui/package.json`
- `ui/index.html`
- `ui/vite.config.ts`
- `ui/tsconfig.json`
- `ui/src/main.tsx`
(+ `ui/package-lock.json` generado por `npm install`)

**Estructura esperada:**
- `package.json`: `"name": "tuki-ui"`, `"private": true`, `"type": "module"`, `"license": "MPL-2.0"`.
  - scripts: `"dev": "vite"`, `"build": "tsc --noEmit && vite build"`, `"preview": "vite preview"`.
  - dependencies: `react`, `react-dom` (última estable).
  - devDependencies: `typescript`, `vite`, `@vitejs/plugin-react`, `@types/react`, `@types/react-dom` (últimas estables compatibles entre sí).
- `vite.config.ts`: `plugins: [react()]`, `clearScreen: false`, `server: { port: 5173, strictPort: true }`.
- `tsconfig.json`: `strict: true`, `noEmit: true`, `jsx: "react-jsx"`, `module: "ESNext"`, `moduleResolution: "bundler"`, `target: "ES2022"`, `lib: ["ES2022", "DOM", "DOM.Iterable"]`, `skipLibCheck: true`, `include: ["src"]`.
- `index.html`: `<div id="root">`, `<title>tukitermlulu</title>`, script `type="module"` a `/src/main.tsx`.
- `src/main.tsx`: obtiene `#root` **sin aserción no-null** (si no existe, `throw new Error("Root element #root not found")`), y hace `createRoot(...).render(<StrictMode><main>tukitermlulu</main></StrictMode>)`. Sin `any`.

**Criterios de aceptación (verificables):**
- [ ] `npm --prefix ui install` termina sin errores y genera `ui/package-lock.json`.
- [ ] `npm --prefix ui run build` (tsc + vite) en verde y genera `ui/dist/index.html`.
- [ ] `npm --prefix ui audit --audit-level=high` sin vulnerabilidades altas/críticas.
- [ ] El gate de Rust sigue en verde (no se toca ningún crate).

**Tests requeridos:** ninguno (scaffold sin lógica; Vitest llega en T-02).
**Commit:** `chore(ui): scaffold react typescript vite app [T-01c]`

**Fuera de alcance:** Tauri, `@tauri-apps/*`, Tailwind, Zustand, xterm, ESLint, Prettier, Vitest, `ui/src/lib/api.ts`, componentes adicionales.
