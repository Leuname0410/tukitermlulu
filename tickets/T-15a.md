## T-15a: Wire Tauri commands and the binary terminal channel in the desktop crate
**Fase:** F3  **Depende de:** T-14 · **ADR:** 005
**Contexto:** Composition root. Control por `invoke`; la salida del PTY va por un `tauri::ipc::Channel` en **binario** (nunca JSON, nunca estado de React); la entrada de teclado llega como **cuerpo raw** de `invoke`. Hasta que exista el repositorio (T-18), la sesión llega descrita en los argumentos del comando.

**Archivos a crear/modificar:**
- `crates/adapters/src/ssh_transport.rs` (modificar: `RusshTransport` pasa a ser `Clone` barato — estado interno en un `Arc<Inner>` — para compartirlo entre el caso de uso y los comandos)
- `crates/desktop/Cargo.toml` (modificar: `tuki-core`, `tuki-application`, `tuki-adapters` por path; `tokio = { version = "1", features = ["time"] }`; `serde = { version = "1", features = ["derive"] }`; `zeroize = { version = "1", features = ["serde"] }`)
- `crates/desktop/src/main.rs` (modificar: estado, `invoke_handler` con los 4 comandos)
- `crates/desktop/src/terminal.rs` (crear: DTOs, `ChannelSink`, comandos)

**Interfaces / firmas esperadas (`terminal.rs`):**
```rust
pub struct AppState { transport: RusshTransport, known_hosts_path: PathBuf }   // known_hosts en app_data_dir()/known_hosts; se crea en setup()

#[derive(Deserialize)] #[serde(tag = "kind", rename_all = "snake_case")]
pub enum AuthArgs { Password { remember: bool }, Key { path: String, has_passphrase: bool } }
#[derive(Deserialize)] #[serde(rename_all = "camelCase")]
pub struct ConnectArgs { host: String, port: u16, username: String, auth: AuthArgs,
    password: Option<Zeroizing<String>>, passphrase: Option<Zeroizing<String>>,
    approved_fingerprint: Option<String>, rows: u16, cols: u16 }            // sin Debug derivado (o Debug manual con [REDACTED])

#[derive(Serialize)] #[serde(tag = "kind", rename_all = "snake_case")]
pub enum ConnectResponse { Connected { connection_id: u64, channel_id: u64 }, NeedsHostKeyApproval { fingerprint: String }, NeedsPassword, NeedsPassphrase }
#[derive(Serialize)] #[serde(rename_all = "camelCase")]
pub struct CommandError { kind: &'static str, message: String, fingerprint: Option<String> }  // message = Display del error de dominio (literales); kind: "invalid_input" | "host_key_changed" | "auth_rejected" | "wrong_passphrase" | "timeout" | "not_connected" | "io"

#[derive(Serialize, Clone)] pub struct TerminalClosed { exit_status: Option<u32> }
pub struct ChannelSink { output: Channel<InvokeResponseBody>, closed: Channel<TerminalClosed> }  // impl PtySink: data → output.send(InvokeResponseBody::Raw(bytes.to_vec())); errores de envío se ignoran

#[tauri::command] async fn connect(state, args: ConnectArgs, on_output: Channel<InvokeResponseBody>, on_closed: Channel<TerminalClosed>) -> Result<ConnectResponse, CommandError>;
    // construye Host/Session(SessionId::new(0))/PtySize validados (error → invalid_input), ConnectSession::new(state.transport.clone(), FileHostKeyVerifier::new(path), RusshKeyLoader, KeyringSecretStore::new("tukitermlulu"))
    // y lo ejecuta dentro de tokio::time::timeout(Duration::from_secs(20)) → "timeout"
#[tauri::command] async fn terminal_write(state, request: tauri::ipc::Request<'_>) -> Result<(), CommandError>;  // InvokeBody::Raw(bytes); channel id en el header "x-channel-id"
#[tauri::command] async fn terminal_resize(state, channel_id: u64, rows: u16, cols: u16) -> Result<(), CommandError>;
#[tauri::command] async fn disconnect(state, connection_id: u64) -> Result<(), CommandError>;
```
- Ningún secreto en logs, `Debug`, errores ni en `ConnectResponse`. Los `Zeroizing<String>` se convierten a `SecretString` y se sueltan al terminar `connect`.
- `main.rs`: sin `unwrap`/`expect`; si `app_data_dir()` falla en `setup`, se devuelve el error.
