## T-01d: Add the Tauri 2 `desktop` crate that opens an empty window
**Fase:** F0  **Depende de:** T-01c
**Contexto:** Última parte del scaffold: crate `crates/desktop` (composition root de Tauri 2) que carga la UI de `ui/`. Criterio de fase: la app abre una ventana vacía. El workspace usa `members = ["crates/*"]`.

**Archivos a crear/modificar:**
- `crates/desktop/Cargo.toml` (crear)
- `crates/desktop/build.rs` (crear)
- `crates/desktop/src/main.rs` (crear)
- `crates/desktop/tauri.conf.json` (crear)
- `crates/desktop/app-icon.svg` (crear: placeholder simple, cuadrado, ≤ 15 líneas)
- `ui/package.json` (modificar)
(+ generados: `crates/desktop/icons/*` con `tauri icon crates/desktop/app-icon.svg -o crates/desktop/icons`, `Cargo.lock`, `ui/package-lock.json`)

**Estructura esperada:**
- `Cargo.toml`: `name = "tuki-desktop"`, hereda los campos `.workspace = true`; `[dependencies] tauri = { version = "2", features = [] }`; `[build-dependencies] tauri-build = { version = "2", features = [] }`. Ninguna otra dependencia (el cableado con adapters llega con el primer caso de uso).
- `build.rs`: `fn main() { tauri_build::build() }`.
- `src/main.rs`:
  - `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`
  - `fn main()` que ejecuta `tauri::Builder::default().run(tauri::generate_context!())`; si devuelve `Err`, escribe el error con `eprintln!` y sale con `std::process::exit(1)`. **Sin `unwrap`/`expect`.**
- `tauri.conf.json` (Tauri 2, `$schema` oficial):
  - `productName: "tukitermlulu"`, `version: "0.1.0"`, `identifier: "dev.tukitermlulu.desktop"` (no puede terminar en `.app`).
  - `build`: `devUrl: "http://localhost:5173"`, `frontendDist` apuntando a `ui/dist`, `beforeDevCommand`/`beforeBuildCommand` que ejecuten `npm run dev` / `npm run build` dentro de `ui/` (usa la forma objeto `{ script, cwd }` con la ruta relativa correcta).
  - `app.windows`: una ventana `title: "tukitermlulu"`, 1200×800.
  - `app.security.csp`: `"default-src 'self'; style-src 'self' 'unsafe-inline'"`. `app.withGlobalTauri: false`.
  - `bundle.icon`: los iconos generados en `icons/`.
  - **Sin** `capabilities` ni plugins (ventana vacía: mínimo privilegio).
- `ui/package.json`: añade `@tauri-apps/cli` (v2 estable) a `devDependencies` y el script `"tauri": "tauri"`.
  - Si la CLI no encuentra `crates/desktop` al ejecutarse desde `ui/`, usa la variable de entorno `TAURI_APP_PATH=../crates/desktop` al invocarla (no muevas archivos) e indícalo en la Entrega.

**Criterios de aceptación (verificables):**
- [ ] `cargo build --workspace` compila `tuki-desktop`.
- [ ] `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` en verde.
- [ ] `npm --prefix ui run build` sigue en verde.
- [ ] `tauri dev` (vía el script de `ui/package.json`) arranca Vite y abre una ventana titulada "tukitermlulu" que muestra el texto `tukitermlulu`.
- [ ] `tauri build --no-bundle` compila el binario release.
- [ ] `src/main.rs` sin `unwrap`/`expect`/`panic!`.
