## T-18c: Wire the session repository and session commands into Tauri and api.ts
**Fase:** F4  **Depende de:** T-18b · **ADR:** 004
**Contexto:** Composition root del gestor de sesiones. El repositorio SQLite vive en `app_data_dir()/sessions.db`. **Interfaces / firmas esperadas (`sessions.rs`):**
```rust

#[derive(Serialize, Deserialize)] #[serde(tag = "kind", rename_all = "snake_case")]
pub enum AuthDto { Password { remember: bool }, Key { path: String, #[serde(rename = "hasPassphrase")] has_passphrase: bool } }
#[derive(Deserialize)] #[serde(rename_all = "camelCase")]
pub struct SessionInput { name: String, host: String, port: u16, username: String, auth: AuthDto, folder: Option<u64> }   // validado con los constructores del dominio
#[derive(Deserialize)] #[serde(tag = "kind", rename_all = "snake_case")]
pub enum PasswordInput { Keep, Set { value: Zeroizing<String> }, Forget }   // sin Debug derivado
#[derive(Serialize)] #[serde(rename_all = "camelCase")] pub struct FolderDto { id: u64, name: String, parent: Option<u64> }

#[tauri::command] async fn list_sessions(state) -> Result<Vec<SessionDto>, CommandError>;     // password_saved = secrets.get(..).is_some(); el valor se suelta al instante
#[tauri::command] async fn create_session(state, input: SessionInput, password: Option<Zeroizing<String>>) -> Result<SessionDto, CommandError>;
#[tauri::command] async fn update_session(state, id: u64, input: SessionInput, password: PasswordInput) -> Result<(), CommandError>;
#[tauri::command] async fn duplicate_session(state, id: u64) -> Result<SessionDto, CommandError>;
#[tauri::command] async fn delete_session(state, id: u64) -> Result<(), CommandError>;
#[tauri::command] async fn list_folders(state) -> Result<Vec<FolderDto>, CommandError>;

```
- `CommandError` (reutilizado de `terminal.rs`, hazlo `pub(crate)`): `SessionError::Domain` → `invalid_input`; `Repository(NotFound)` → `not_found`; `Repository(Conflict)` → `conflict`; resto → `io`.
- `connect` con `session_id = Some(id)`: `repository.get_session(id)` (ausente → `not_found`) y usa esa sesión; `host/port/username/auth` de los args se ignoran. Con `None` sigue la conexión rápida actual.
- El `SecretStore` (`KeyringSecretStore::new("tukitermlulu")`) se construye en un solo sitio (helper) y se reutiliza.
- Ningún secreto en `SessionDto`, `Debug`, errores ni logs.

**`api.ts`:** `listSessions()`, `createSession(input, password?)`, `updateSession(id, input, password: PasswordInput)`, `duplicateSession(id)`, `deleteSession(id)`, `listFolders()`, `saveFolder({ id?, name, parent? })`, `deleteFolder(id)`, y `ConnectArgs.sessionId?: number`. Tipos `SessionDto`, `SessionInput`, `PasswordInput = { kind: "keep" } | { kind: "set"; value: string } | { kind: "forget" }`, `FolderDto`, con validación de la respuesta sin `any` (mismo estilo que `parseConnectResponse`).
