## T-07a: Add domain errors and the Host, Port and RemotePath value objects
**Fase:** F1  **Depende de:** T-05b (independiente de T-06)
**Contexto:** Primeros value objects del dominio con constructor validado. `core` sigue sin I/O ni dependencias salvo `thiserror`.

**Archivos a crear/modificar:**
- `crates/core/Cargo.toml` (modificar: `thiserror = "2"`)
- `crates/core/src/lib.rs` (modificar: `pub mod error; pub mod host; pub mod remote_path;`)
- `crates/core/src/error.rs` (crear)
- `crates/core/src/host.rs` (crear)
- `crates/core/src/remote_path.rs` (crear)

**Interfaces / firmas esperadas:**
```rust
// error.rs
#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum DomainError {
    #[error("port must be between 1 and 65535")] InvalidPort,
    #[error("host must not be empty")] EmptyHost,
    #[error("host contains invalid characters")] InvalidHost,
    #[error("username must not be empty")] EmptyUsername,
    #[error("remote path must not be empty")] EmptyRemotePath,
    #[error("remote path must not contain NUL bytes")] InvalidRemotePath,
}
// host.rs
pub struct Port(u16);        impl Port { pub fn new(v: u16) -> Result<Self, DomainError>; pub fn get(self) -> u16; }  // Default = 22
pub struct Hostname(String); impl Hostname { pub fn new(v: &str) -> Result<Self, DomainError>; pub fn as_str(&self) -> &str; }
pub struct Username(String); impl Username { pub fn new(v: &str) -> Result<Self, DomainError>; pub fn as_str(&self) -> &str; }
pub struct Host { pub hostname: Hostname, pub port: Port, pub username: Username }
// remote_path.rs: ruta remota POSIX o Windows tal cual la reporta el servidor
pub struct RemotePath(String);
impl RemotePath { pub fn new(v: &str) -> Result<Self, DomainError>; pub fn as_str(&self) -> &str; pub fn parent(&self) -> Option<RemotePath>; pub fn join(&self, name: &str) -> Result<RemotePath, DomainError>; }
```
Derivar `Debug, Clone, PartialEq, Eq` (y `Copy` en `Port`). `Hostname`: trim; rechaza espacios internos y caracteres de control; acepta IPv4, IPv6 entre corchetes o no, y nombres DNS.

**Criterios de aceptación (verificables por test):**
- [ ] `Port::new(0)` → `InvalidPort`; `1` y `65535` → Ok; `Port::default().get() == 22`.
- [ ] `Hostname::new("")`/`"   "` → `EmptyHost`; `"a b"`/`"a\tb"` → `InvalidHost`; `"example.com"`, `"10.0.0.1"`, `"::1"`, `"[::1]"` → Ok.
- [ ] `Username::new("")` → `EmptyUsername`.
- [ ] `RemotePath::new("")` → `EmptyRemotePath`; con `\0` → `InvalidRemotePath`.
- [ ] `parent()`: `"/a/b"`→`"/a"`, `"/a"`→`"/"`, `"/"`→`None`. `join("/a", "b")`→`"/a/b"`; `join("/", "b")`→`"/b"`; `join` con `name` vacío, `.`, `..`, o que contenga `/` o `\` → `InvalidRemotePath` (anti path traversal, también en servidores Windows).
- [ ] `tuki-core` solo depende de `thiserror`.

**Tests requeridos:** unit (`#[cfg(test)] mod tests` en cada archivo), `should_<resultado>_when_<condición>`.
**Commits:** `test(core): host, port and remote path invariants [T-07a]` → `feat(core): host, port and remote path value objects [T-07a]`
