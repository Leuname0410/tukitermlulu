## T-34c: `logUiError`, UI errors in the backend log
**Fase:** F7  **Depende de:** T-32c · **Regla:** AGENTS.md, sección "Logs"
**Contexto:** AGENTS.md exige que todo `catch` de la UI registre el error con `logUiError` de `ui/src/lib/api.ts`. Este ticket crea esa función y el comando del backend. Aplicarla a los `catch` existentes queda para la auditoría posterior a F8.

**Archivos a crear/modificar:**
- `crates/desktop/src/ui_log.rs` (crear: comando `log_ui_error(scope: String, message: String)` + tests)
- `crates/desktop/src/main.rs` (modificar: `mod ui_log;` y registrar el comando)
- `ui/src/lib/api.ts` + `ui/src/lib/api.test.ts` (modificar: `logUiError(scope: string, error: unknown): void`)

**Reglas:**
- Backend:
  - `scope` se recorta a 64 caracteres y solo admite `[A-Za-z0-9_.-]`; lo demás se sustituye por `_`.
  - `message` se recorta a 1024 caracteres y pasa por la misma redacción de `campo=valor` que el diagnóstico (reutiliza `redact_line` de `diagnostics.rs`, haciéndolo `pub(crate)`).
  - Emite `tracing::warn!(event = "ui_error", scope, message)`. El comando nunca falla: devuelve `()`.
- UI:
  - `logUiError` extrae el mensaje (`CommandError` → `kind: message`; `Error` → `name: message`; otro → `String(error)`) y llama a `invoke("log_ui_error", ...)` **sin `await`** (fire-and-forget), con `.catch(() => {})`.
  - Ese `.catch` vacío es la única excepción permitida a la regla, porque no hay dónde loguear; se documenta con un comentario.
  - Además, `console.error(scope, error)` solo en desarrollo (`import.meta.env.DEV`).
- Nada de `any`.

**Criterios de aceptación:**
- [ ] Rust:
  - `sanitize_scope("tabs/connect!")` → `tabs_connect_`;
  - un scope de 100 caracteres se recorta a 64;
  - un message con `password=abc` queda como `password=[REDACTED]`;
  - un message de 5000 caracteres se recorta a 1024 (en un límite de `char`, sin panic con UTF-8 multibyte).
- [ ] Vitest:
  - `logUiError("x", new Error("boom"))` llama a `invoke` con `{scope:"x", message:"Error: boom"}`;
  - con un `CommandError` usa `kind: message`;
  - si `invoke` rechaza, no lanza ni deja una promesa sin manejar.
- [ ] `just check` en verde.

**Commits:** `test(desktop): ui error logging [T-34c]` → `feat(desktop): log ui errors to the backend log [T-34c]`

**Fuera de alcance:** cambiar los `catch` existentes (auditoría posterior a F8).
