## T-26b: Add the SFTP sidebar context menu and the transfer list
**Fase:** F5  **Depende de:** T-26a
**Contexto:** Clic derecho sobre una entrada del sidebar (o sobre el fondo) abre un menú con las acciones de archivo. Debajo del sidebar, una lista compacta de transferencias con progreso y botón de cancelar (eventos de T-22c).

**Archivos a crear/modificar:**
- `ui/src/sftp/EntryMenu.tsx` (crear: menú `role="menu"` con `menuitem`; cierra con Escape o clic fuera, como en T-16)
- `ui/src/sftp/PermissionsDialog.tsx` (crear: `<dialog>` con casillas rwx para propietario, grupo y otros y un campo octal sincronizado; validación 0–7777)
- `ui/src/sftp/TransferList.tsx` (crear: `onTransfers` → lista con nombre, `<progress>`, estado y "Cancelar"; "Limpiar terminadas")
- `ui/src/sftp/SftpSidebar.tsx` (modificar: abrir el menú y montar `TransferList`)
- `ui/src/sftp/menu.test.tsx` (crear)

**Acciones del menú:**
- **Descargar** (solo archivos): `enqueueDownload(conn, path, await downloadsDir())`.
- **Renombrar**: un input inline con el nombre seleccionado → `sftpRename` dentro de la misma carpeta. Un nombre con `/`, vacío, `.` o `..` se rechaza en cliente.
- **Borrar**: `confirm` nativo con el nombre → `sftpRemove`. Para una carpeta no vacía, se muestra el error del backend.
- **Nueva carpeta** (también sobre el fondo): mismo input y mismas reglas → `sftpMkdir`.
- **Copiar ruta**: `navigator.clipboard.writeText(path)`.
- **Permisos…**: solo si `permissions` no es `undefined` (servidores Unix) → `PermissionsDialog` → `sftpChmod`.

Tras cada mutación, se vuelve a listar. Los errores se muestran en la barra del sidebar.

**Criterios de aceptación (Vitest + Testing Library, mocks de `../lib/api`):**
- [ ] Cada acción del menú llama a la API correcta con la ruta correcta y luego refresca.
- [ ] Renombrar con `a/b` o vacío no llama a la API y muestra el error.
- [ ] Borrar cancelado en `confirm` no llama a `sftpRemove`.
- [ ] "Permisos…" no aparece sin `permissions`. El diálogo sincroniza las casillas con el octal (`0o754` ↔ rwxr-xr--).
- [ ] `TransferList`: un evento `running` muestra el `<progress>` con su valor; "Cancelar" llama a `cancelTransfer`; "Limpiar terminadas" llama a `clearTransfers`.
- [ ] `just check` en verde.

**Commits:** `test(ui): sftp context menu and transfer list [T-26b]` → `feat(ui): sftp context menu, permissions and transfer list [T-26b]`

**Fuera de alcance:** elegir carpeta de descarga con diálogo nativo, multiselección, borrar recursivo.
