## T-01a: Create the Cargo workspace and the `core` crate
**Fase:** F0  **Depende de:** —
**Contexto:** Primer paso del scaffold (T-01 dividido en a/b/c/d). Solo workspace Rust + crate de dominio vacío. Cargo no permite un paquete llamado `core`, así que los paquetes llevan el prefijo `tuki-` (el directorio sigue siendo `crates/core`).

**Archivos a crear:**
- `Cargo.toml` (raíz, workspace virtual)
- `.gitignore`
- `crates/core/Cargo.toml`
- `crates/core/src/lib.rs`
(+ `Cargo.lock` generado por cargo)

**Estructura esperada:**
- `Cargo.toml` raíz:
  - `[workspace]` con `resolver = "3"` y `members = ["crates/*"]` (glob: los crates siguientes no tocan este archivo).
  - `[workspace.package]`: `edition = "2024"`, `license = "MPL-2.0"` (coincide con `LICENSE`), `version = "0.1.0"`, `rust-version = "1.85"`.
- `crates/core/Cargo.toml`: `name = "tuki-core"`, hereda `edition/license/version/rust-version` con `.workspace = true`. **Sin dependencias.**
- `crates/core/src/lib.rs`: solo un doc comment de crate en español (`//! Dominio puro: entidades, value objects y puertos. Sin I/O.`). Sin código.
- `.gitignore`: `target/`, `node_modules/`, `dist/`, `.DS_Store`.

**Criterios de aceptación (verificables):**
- [ ] `cargo build --workspace` compila.
- [ ] `cargo fmt --all -- --check` sin cambios.
- [ ] `cargo clippy --workspace --all-targets -- -D warnings` sin warnings.
- [ ] `cargo test --workspace` pasa (0 tests es válido).
- [ ] `tuki-core` no tiene ninguna dependencia.

**Tests requeridos:** ninguno (scaffold sin lógica; no aplica `test:` → `feat:`).
**Commit:** `chore(core): create cargo workspace and core crate [T-01a]`

**Fuera de alcance:** otros crates, UI, Tauri, justfile, CI, lints de workspace, cualquier dependencia.
