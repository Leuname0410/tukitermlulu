## T-17a: Keep the key passphrase in backend memory per tab
**Fase:** F3  **Depende de:** T-16 · **ADR:** 004
**Contexto:** La passphrase de la llave nunca se persiste (ni disco ni keyring). Se retiene en memoria del backend por pestaña, como `SecretString` (zeroize al soltarse), para reconectar sin volver a pedirla. Cerrar la pestaña la borra. La política vive en `application`; `desktop` solo la cablea.

**Archivos a crear/modificar:**
- `crates/application/src/lib.rs` (modificar: `pub mod connect_tab;`)
- `crates/application/src/connect_tab.rs` (crear: `TabId`, `TabPassphrases`, `ConnectTab` + tests unitarios)
- `crates/desktop/src/terminal.rs` (modificar: `AppState.passphrases`, `connect` con `tab_id`, nuevo comando `close_tab`)
- `crates/desktop/src/main.rs` (modificar: registrar `close_tab`)

**Interfaces / firmas esperadas (`connect_tab.rs`):**
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)] pub struct TabId(u64);   // new(u64), get()
#[derive(Default)] pub struct TabPassphrases { entries: std::sync::Mutex<HashMap<TabId, SecretString>> }
impl TabPassphrases {
    pub fn new() -> Self;
    fn copy_of(&self, tab: TabId) -> Option<SecretString>;   // copia con SecretString::new(s.expose()); el lock nunca cruza un .await
    fn remember(&self, tab: TabId, passphrase: SecretString);
    pub fn forget(&self, tab: TabId);                      // quita la entrada (drop → zeroize)
}
pub struct ConnectTab<'a, T, V, K, S> { connect: ConnectSession<T, V, K, S>, passphrases: &'a TabPassphrases }
impl<..> ConnectTab<'a, T, V, K, S> {
    pub fn new(connect: ConnectSession<T, V, K, S>, passphrases: &'a TabPassphrases) -> Self;
    pub async fn execute(&self, tab: TabId, request: ConnectRequest<'_>) -> Result<ConnectOutcome, ConnectError>;
}
```
- Mutex envenenado: `lock().unwrap_or_else(PoisonError::into_inner)`; sin `unwrap`/`expect`.

**Reglas de `execute`:**
1. Passphrase efectiva = `request.passphrase` si viene; si no, la copia retenida para `tab` (si hay).
2. `Ok(Connected)` con sesión `PublicKey` y passphrase efectiva → `remember(tab, copia)`.
3. `Ok(NeedsPassphrase)` o `Err(Key(WrongPassphrase))` → `forget(tab)` (una passphrase incorrecta nunca queda retenida).
4. Cualquier otro resultado → no cambia la memoria.

**`desktop/terminal.rs`:**
- `AppState` gana `passphrases: TabPassphrases`.
- `connect(state, tab_id: u64, args, on_output, on_closed)` usa `ConnectTab::new(ConnectSession::new(..), &state.passphrases).execute(TabId::new(tab_id), request)`.
- `#[tauri::command] fn close_tab(state, tab_id: u64)` → `state.passphrases.forget(..)`. No desconecta: la UI llama a `disconnect` aparte.

**Criterios de aceptación (unit con `mockall` + `block_on`, sin runtime):**
- [ ] Conectar con passphrase y luego reconectar la misma pestaña sin passphrase → `keys.load` recibe la passphrase retenida y el resultado es `Connected` (no `NeedsPassphrase`).
- [ ] Tras `forget(tab)`, reconectar sin passphrase → `NeedsPassphrase`.
- [ ] `WrongPassphrase` → no se retiene; si había una retenida, se borra (el siguiente intento sin passphrase da `NeedsPassphrase`).
- [ ] La passphrase de una pestaña no se usa para otra (`TabId` distinto → `NeedsPassphrase`).
- [ ] Sesión con contraseña: nada queda retenido.
- [ ] Ningún camino llama a `SecretStore::set` (el mock no lo espera).
- [ ] `just check` en verde; los tests de `desktop` existentes siguen pasando.
